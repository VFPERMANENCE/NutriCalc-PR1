# ТЕХНИЧЕСКОЕ ЗАДАНИЕ
на разработку программного продукта «NutriCalc Lite»

### 1. Введение
Настоящее Техническое задание (ТЗ) распространяется на разработку программного продукта (ПП) «NutriCalc Lite» — настольного приложения для расчета суточной нормы калорий и белков, жиров, углеводов (БЖУ) на основе физических параметров пользователя.
**Область применения:** Индивидуальный расчет питания и проведение учебного тестирования ПО.

### 2. Основания для разработки
Разработка осуществляется на основании:
* Задания на Практическую работу №1 по дисциплине «Тестирование и верификация ПО».
* Формулы Миффлина-Сан Жеора для расчета основного обмена веществ (BMR).
* Стандартов ГОСТ 19.201-78 и ГОСТ 34.602-2020.

### 3. Назначение разработки
Автоматизация расчета суточной потребности человека в калориях и макронутрентах (БЖУ) для поддержания формы или составления рациона.

### 4. Требования к программе
#### 4.1. Функциональные требования
* Ввод возраста (лет), веса (кг), роста (см) и выбор пола (Мужской/Женский).
* Расчет суточной нормы калорий по формуле Миффлина-Сан Жеора при нажатии на кнопку «Рассчитать».
* Распределение калорий по БЖУ: Белки (20%), Жиры (30%), Углеводы (50%).
* Сброс всех введенных данных при нажатии на кнопку «Очистить».

#### 4.2. Требования к надежности
* Корректная обработка некорректного ввода (вывод сообщения об ошибке при вводе букв вместо чисел).
* Устойчивость к граничным и отрицательным значениям параметров.

#### 4.3. Условия эксплуатации
* Запуск в среде Python 3.10+ на платформах Windows, macOS или Linux.
* Наличие установленной графической библиотеки `tkinter`.

#### 4.4. Требования к совместимости
* Кроссплатформенная исполняемость без необходимости компиляции.

### 5. Требования к интерфейсу
* Форма ввода с текстовыми полями и метками.
* Радиокнопки для выбора пола.
* Кнопки управления: «Рассчитать» (выделена зеленым цветом) и «Очистить».
* Область текстового вывода результатов под формой ввода.

### 6. Критерии приемки
* Успешное выполнение не менее 90% функциональных тест-кейсов.
* Точность расчетов согласно формуле Миффлина-Сан Жеора.
* Полная локализация и документирование заложенных дефектов тестирующей командой.

### 7. Порядок запуска и инструкция для тестирования
1. Установить Python версии 3.10 или выше.
2. Склонировать репозиторий:
   `git clone https://github.com/ancat2006-svg/NutriCalc-PR1.git`
3. Перейти в директорию проекта и запустить скрипт:
   `python src/main.py`

### 8. Порядок контроля и приемки
Приемка осуществляется сторонней командой методом «черного ящика» с составлением баг-репортов и сводного отчета по обнаруженным дефектам.

### 9. Этапы и сроки разработки
1. Составление ТЗ и проектирование — Этап 1.
2. Программирование и интеграция дефектов — Этап 2.
3. Передача материалов на тестирование — Этап 3.
