# Описание преднамеренно внесенных ошибок (Служебный документ)

1. **Логическая ошибка (Расчет BMR):** В формуле Миффлина-Сан Жеора для женщин используется значение `+ 5` вместо `- 161`.
2. **Отсутствие валидации границ:** Приложение принимает отрицательные значения возраста, веса и роста, выдавая отрицательные калории.
3. **Падение программы (ZeroDivisionError):** При вводе значения `0` в поле «Возраст» происходит деление на ноль и аварийное завершение работы.
4. **Некорректное форматирование вывода:** Дробные результаты БЖУ вычисляются без округления (`round()`), что приводит к выводу чисел с 14+ знаками после запятой.
5. **Интерфейсный дефект:** В блоке результатов вместо термина «Углеводы» отображается «Углероды».
6. **Ошибка логики интерфейса:** Кнопка «Очистить» вызывают повторный расчет `calculate_calories()` вместо сброса значений в текстовых полях.
