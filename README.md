# NutriCalc Lite

Учебный программный продукт «NutriCalc Lite» — калькулятор суточной нормы калорий и БЖУ на Python (Tkinter). Разработан в рамках Практической работы №1 по дисциплине «Тестирование и верификация ПО».

## Структура репозитория
* `src/main.py` — Исходный код приложения.
* `docs/TZ_NutriCalc.md` — Техническое задание (ТЗ).

## Требования
* Python 3.10 или выше.
* Модуль `tkinter` (входит в стандартную поставку Python).
